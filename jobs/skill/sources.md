# Source registry

Find the current notification with `WebSearch` (`<organisation> recruitment <month> <year>`), then open it on the official domain below. A domain marked (?) has not been confirmed in a run yet: confirm it on first use and remove the mark (data edit, no version bump).

|---|---|---|
| UPSC | upsc.gov.in | ESE (E&T for ECE), CDS, CAPF AC, EPFO EO/AO & APFC, IES/ISS (not B.Tech/B.Com), CSE |
